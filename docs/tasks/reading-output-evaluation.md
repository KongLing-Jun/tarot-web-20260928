# 解读输出真实模型评估

本报告使用明确标记为测试用途的固定问题、牌阵、牌面和追问历史，不读取用户会话。调用项目当前服务端配置中的模型；请求直接发送到该配置的上游接口，使用实际 `lib/api/prompts.ts` 构建提示词。此评估验证真实模型输出，不代表微信登录、业务 API、SSE 展示或真机体验已经验证。

历史执行命令（当时路径）：

```text
npx tsx scripts/evaluate-reading-output.ts --run --timeout-ms 180000 --max-output-tokens 16384 --output tasks/reading-output-evaluation
```

每类固定输入请求两次，六种牌阵加直接追问、补牌追问，共 16 份目标样例；并发不超过 2。单请求超时和输出 token 预算由上述执行参数指定。配置、凭据、原始错误响应和模型内部思考不写入结果。每份 `.prompt.md` 保存实际提示词，`.md` 保存用户可见正文，`.json` 保存状态、输入摘要、结构检查和 token 用量；全部完成后的 `results.json` 汇总最终批次。

文档整理后仅保留本报告，原始提示词、模型输出、JSON 及批次子目录已删除。下文中的目录名、文件名和样例编号描述历史执行过程，不再对应可打开的附件。后续运行请将 `--output` 指向临时目录；超时和输出预算按本次评估所用配置填写。本次仅整理报告，未重新调用模型。

## 评阅口径

逐份阅读正文及专业解释，分别检查：直接回应问题；不编造背景或断言他人心理与结果；建议承接前文且能实际执行；专业说明覆盖需要的牌位并与通俗判断一致；中文表达自然，不机械列出内部写作检查项。判断由本次执行代理逐份阅读原文后给出，不是独立真人用户测试或统计意义的模型评测，也不保证所有未来生成都一致。

若出现问题，只写具体表现及其影响，不把 HTTP 成功或结构正确当成话术质量通过。微信开发者工具、iOS 和 Android 微信真机不在本报告验证范围。
