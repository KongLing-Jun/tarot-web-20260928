# 行动建议评分 v2：离线修订与材料冻结

## 结论与边界

按用户确认的五项修订实现 `action-v2`，本轮只做规则、开发材料、校验器和离线回归。未指定真实裁判模型或调用预算，未发起模型请求；没有修改线上 P0、生成提示词或实现单变量候选。v1 的 rubric、样例和已运行产物保留，7/24 的历史结果不重算。

## 可观察评分问题

| 维度 | 检查的问题 | 不能替代的判断 |
| --- | --- | --- |
| 目标承接 | 动作服务哪个当前目标，是否漏掉明确子目标，是否换成拒绝/撤回的目标 | 步骤不够具体不自动等于换目标 |
| 可执行性 | 下一步、控制权、已知限制、关键依赖和反馈是否可辨识 | 不能仅以目标不对或正文有事实错连带扣分 |
| 现实条件依据 | 陈述、话术前提和预设是否有来源；未知是否保持未知 | 糟糕的命令或未来提议不自动等于事实编造 |

允许有独立证据的多维扣分。联合标签以完整三维分数组合存储，不将各维允许值自由拼接；倾诉时执行仍为 null。新增必要澄清场景允许目标 1 或 2 的两个预先说明理由的组合，但执行固定为 0、事实固定为 2。该范围在任何新模型调用之前冻结。

## 严重错误证据规则

每个必需识别的事实错误有一个 ID 和若干合法原文行。校验规则为：

1. 每个必需错误至少命中一个合法位置，不要求把同一个错误的所有出现位置重复报告。
2. 报告多个合法位置可接受；漏掉另一个独立必需错误不可接受。
3. 任何严重错误引用必须是登记的完整原文行。引用正常行、只因为执行错误而报编造，或用整篇回答笼统覆盖目标句，均不能通过。
4. 合理回答的严重错误误报仍单独检查；1 分含混案例不强制报告严重编造。

这是原文位置与标签的程序校验，不验证理由是否成立。真实调用后，必须逐例复核理由有没有指出对应事实、是否有独立扣分依据、是否把合法条件句误判为编造。汇总将自动检查与人工语义复核分开，始终显式给出 `manualReviewRequired: true`、`candidateComparisonReady: false`，不能凭 `allPassed` 自动进入候选对照。
