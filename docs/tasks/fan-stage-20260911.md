## 已确认并实现

- 删除顶部整排阵位名称、待抽取占位牌、逐牌撤回和预留空间；移除重复大标题，仅保留问题、牌阵和进度，牌堆紧接进度区域。
- 默认仍为 100% 的完整半圆环，不以初始放大裁切换取视觉尺寸。保留沿弧拨牌、75%—200% 双指缩放、双指平移和径向拖出。
- 确认后原牌留空，更新“已抽 / 下一张”提示；移除 CardFlight、飞行目标测量及样式。拖出时的浮层保留，底部“抽取这张”使用同一确认路径。
- “撤回上一张”归还最后一个已填位置的原牌，其余选择不变；未抽牌时禁用，修改问题、修改牌阵和重新洗牌仍可用。
- 每次确认先提交选择，再使用 reducer 对更新后的 slots 校验完整性。最后一张自动进入揭牌，初始揭开数量为 0；页面挂载不触发自动跳转。
- 揭牌前返回调整保留已选牌，满额时可“返回揭牌”；撤回并补选后再次自动进入揭牌。首次揭牌才保存，卡牌身份、顺序及正逆位不变。
