## 视觉对照与修正

参考为计划第 3 节的四张准确原图；统一问题及三张牌样例只用于测试。真实截图视口为 390 × 844，参考等比例缩放至 390px 宽并排比较，没有把图稿拉伸成实际页面。

| 发现 | 处理及结果 |
| --- | --- |
| 原三张牌在手机上排成两行 | 三张完整横排，单张居中，五张保持顺序换行 |
| 牌名出现、进度提示换行带动牌位移动 | 预留牌名、进度和返回入口高度；常规与 200% 文字场景对比全部牌位坐标通过 |
| 文字放大后狐狸侵入问题区 | 狐狸受容器百分比约束，问题自然换行，标题可随文字增长 |
| 中央挑战牌说明拥挤、全揭后丢失牌位标签 | 分开牌位与身份说明并预留高度，保留“2 挑战” |
| 交叉牌遮住图片重试按钮 | 失败牌提高显示层级；真实 404 → 点击重试 → 原图恢复通过 |
| 只靠发光提示下一张 | 同时保留“下一张 · 牌位”、禁用状态和可访问名称 |

已披露的图稿差异：

- 三张全页为 **390 × 849**，与主视口只差 5px；十字全页为 **390 × 1414**，需要纵向滚动。十字参考将文字和操作压得很密，本实现保留可读牌名、至少 44px 的可操作目标、状态稳定和详情入口，未宣称一屏等像素还原。
- 十字切换按钮位于进度下方，沿用组件自身的两种查看方式；参考图的先后位置不同。
- 真实牌图保留项目原图与完整比例，卡背装饰、狐狸和实际字体与生成图有细节差异。桌布纹理和金色轨迹也不是逐像素复制。按钮已由偏红调整为暗金。
- 全揭截图的外侧焦点线来自真实键盘操作，是可用性状态。
