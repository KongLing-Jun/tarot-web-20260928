## 实现范围

- 共享提示词先核对用户当前目标、明确感受、已知限制与拒绝目标，再组织回应；通过正反例区分具体共情与推测内心，覆盖求职自疑、倾诉、选项冲突、过去牌位、目标/情绪纠正和已尝试建议。
- 首轮、直接追问、补牌和每日使用一致事实边界；每日无个人背景时不要求先提问，也不强凑建议。
- 历史构建保留失败、取消、截断回合中的用户补充和真实补牌，仅有效完成的模型回答进入推断上下文。原保存记录与部分正文不变；无需扩展数据库、类型或 API。
- 行动章节按需生成；直接追问可以只给核心回应，首轮与补牌仍要求对应牌义。报告按非空正文展示，单章不显示空行动页、双视角标记或分页。
- 现有解析器和 `Interpretation` 已支持可选章节，复用实现并补回归；质量检查按场景要求章节，仍保留错误牌面、空正文及生成状态的独立处理。
- 扩展现有离线评估脚本，支持准备输入、冻结 Prompt 哈希、固定模型和预算、合成案例及完整结果记录。生产每次生成未增加额外模型调用。

详见 [evaluation.md](evaluation.md)。使用现有服务端模型配置共完成 57 次合成输入的真实生成，没有读取生产聊天记录。最终版 17/17 生成完成，1 个样本保留结构警告；两位 AI 复核分别发现 2 个和 3 个有实质问题的样本，其中 2 个为共同发现。内容质量不能全部验收通过。真实匿名样本与真人盲评尚未取得，计划中的真实样本偏好率也不能标记通过。

第一阶段实际输出发现专业说明把牌义写成未经确认的经历，并存在固定行动章节对倾诉的干扰。因此在记录问题后，先完成方案范围内的可选章节兼容与提示词纠正，再对全部合成案例联合复测；这是工程顺序调整，不是放宽 T6 的真实内容验收门槛。

## 回退与限制

- Prompt 可独立恢复旧版本；既有三段格式仍被新消费者支持。
- 如果已保存可选章节内容，应保留兼容消费者，不能只回退解析/展示导致内容无法完整查看。
- 确定性质量规则无法识别语义共情、所有事实推断或建议适配，不能在线保证“零严重错误”。本轮不增加语义自动拦截或循环重写，也不修改供应商和预算。
- 合成样本、模型自动复核、组件回归和模拟浏览器各有边界；具体剩余内容问题及评审分歧见评估记录。
