## 当前：手机手势抽牌

- 移除可见缩放工具条，使用双指局部缩放（75%—200%）和双指平移；键盘 + / - / 0 保留。
- 单指沿固定牌弧拨牌，预选附近渐进散开、抬起；放大后仍可直接拨牌，视野不随单指移动。
- 沿卡牌径向向外拖动，达到抽取距离后松手抽牌；短拖、回拖、取消和多指接管不提交。底部“抽取这张”继续可用。
- 顶部牌位区、待抽取占位和飞入动画已删除，半圆环默认 100% 紧接进度提示；浮层仅在手指拖出期间展示。抽取后原位留空，可通过“撤回上一张”归还原牌。
- 抽齐后自动进入盖着的揭牌页；揭牌前返回调整不会被自动跳回，选齐状态提供“返回揭牌”。首次揭牌保存规则、牌序与正逆位保持不变。
- 本次实现与验证见[牌堆主视觉调整](./fan-stage-20260911.md)。下面及[历史手势验收](../design-qa.md)中的顶部落位动画、截图和测试数字仅描述当时实现，已由本轮布局替代；微信真机仍待验证。

## 追加：抽牌牌堆缩放

按用户确认，缩放对象是抽牌时的半圆环牌堆。

- 增加缩小、放大和恢复大小按钮；范围75%—200%，每次调整25%，默认100%。调整保留当前视窗中心，不改变预选、已抽牌、牌堆顺序和正逆位。
- 放大后在固定大小的牌堆视窗内拖动查看：手机采用原生触摸滚动，桌面支持鼠标拖动；轻点松手才预选，拖动和取消不切换卡牌。普通大小保留滑过牌环的浏览方式。
- 上一张、下一张及键盘首尾定位将超出视窗的目标带入可见区域。确认抽取仍使用放大后的真实位置和尺寸；飞行期间锁定缩放按钮。
- 浏览器页面原生缩放仍可用；本次没有添加自定义双指局部缩放。
- 新增缩放边界、恢复、身份保持、拖动不误选、取消及禁用回归。完整测试278项通过、15项按配置跳过；TypeScript、lint、生产构建通过，差异检查无空白错误。
- 浏览器脚本扩充75%/125%/200%、移动触摸和桌面拖动、放大后轻点、键盘首尾可见性、页面无横向溢出及放大后的飞行源位置检查。缩放截图使用实际视口，避免整页截图改变嵌套滚动位置。
- 本轮缩放浏览器验收包含 360px 放大预选检查，结论保留于本节。生成附件已清理，iOS / Android 微信真机仍未验证。

## 已实现

- 小程序现有 web-view 内的手动抽牌改为完整78张上半圆环，由同一收拢位置展开。
- 原位置预选、附近5张局部展开、精确上一张/下一张、键盘首末定位；点击按可见卡牌命中，滑动保留起点，取消恢复原预选。
- 确认后从实测源位置抬起、转正并飞入目标牌位；源微光、飞行光尾和落位光晕；牌背在三个位置使用同一归一化画布。
- 牌位条置于牌环上方，多牌阵可横向浏览；抽取前与落位后定位目标。移走的牌保留空位，撤回归还同一索引。
- 同步提交选择后锁定重复操作；动画完成、取消、计时兜底、窗口变化、后台与卸载均有清理。动画失败或减少动态效果模式直接落位。
- 程序化定位已经包含在目标测量中，不会因延迟滚动事件立即结束飞行；只有目标位置继续移动才提前结束。
- 收紧手机标题、牌位和牌堆间距，底部确认区保留安全区；抽牌页返回入口在滚动时有独立背景。

## 实现边界

核心页面接入 ManualDrawTable，内部由 FanDeck、纯几何计算、CompactCardBack 和 CardFlight 分担排布、命中和展示。

复用现有抽牌状态机、洗牌结果、卡牌身份和正逆位。没有更改服务端 API、数据结构、模型输出、自动推荐流程或其他业务页面。保留工作区原有未提交修改，没有提交、推送或部署。

整体体验建议单独记录在 [小程序体验建议](./miniapp-experience-recommendations.md)，作为后续清单，未把建议范围扩展成本轮页面修改。

## 浏览器证据

使用隔离的 Edge / Playwright 会话，模拟登录与服务可用性，运行实际页面、组件和抽牌状态。没有访问真实用户、请求模型或保存业务记录。

- 360×800、390×844、430×932、1440×1000四组流程全部通过，0个页面/console错误，无页面横向溢出和牌环边界裁切。
- 验证真实触摸/指针命中、键盘预选、首尾原位反馈、单张/三张/十张牌阵、飞行锁定、返回调整、撤回、减少动态效果及最终揭牌。
- 对“十张牌阵滚走当前目标→确认抽取”的延迟滚动问题，新增浏览器断言先复现失败，再修复并通过；同步加入单元回归。
- 两轮截图用于布局检查与确认。最后的滚动修复追加无截图功能验证，避免重复视觉调优。
- 当时已检查 390px 飞行动画、360px 预选、430px 十张牌阵及桌面预选；生成附件已清理，保留本节验收结论。

复跑脚本：为运行环境提供含 Playwright 的 NODE_PATH 与 BROWSER_CHANNEL，执行 `node tests/browser/fan-draw.mjs <测试站点URL>`。追加输出目录与 `--no-screenshots` 可只检查功能。
