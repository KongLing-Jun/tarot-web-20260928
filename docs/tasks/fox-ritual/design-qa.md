## 已处理差异

| 发现 | 修改与复核 |
| --- | --- |
| 狐狸被顶部容器裁切、比例过大 | 调整层级、留白与尺寸；主视口和窄屏重新截图 |
| 原牌堆尺寸偏小、展开起点不一致 | 绘制与命中共用几何参数；位移根据真实卡宽/高换算；首中尾展开起点回归测试通过 |
| 中文字重、标题受原页面样式影响 | 两阶段使用局部 Noto Serif Light 子集，实际计算样式为 300，缺字保留系统回退 |
| 主按钮过于平面、悬停时纹理丢失 | 独立浅金纹理，保留真实按钮和禁用状态；修复 hover 背景覆盖 |
| 底栏挤压正文 | 实测底栏高度并预留滚动空间；短屏辅助操作可滚动后点击 |
| 78 张卡背露出部分呈断续金线 | 恢复连续细边，保留完整牌数与真实交互；最终截图复核 |
| Chrome 将触摸事件目标调整到邻牌 | 按触点的可见元素命中；先复现失败，再通过单测和真实浏览器点选断言 |

`baseline/` 留有改动前截图；`iteration-*` 为中间对照，不作为最终交付截图。早期失败截图保留用于追溯。

## 适配结果与明确差异

320 × 740、360 × 800、390 × 844、390 × 659、430 × 932、1440 × 1000 检查无页面横向溢出；图片实际加载，牌堆与固定主操作区不重叠。窄屏辅助操作分行、短屏需要纵向滚动；不是所有操作都强塞入首屏。浏览器脚本实际点击修改问题、修改牌阵、重新洗牌并取消确认。

390 × 844 实现了选定的顶部问题与狐狸、暗紫牌桌、弧形牌堆、辅助操作、浅金主按钮结构。以下属于仍可见的视觉差异，不能声称像素级一致：

- 保留真实 78 张完整牌弧，卡牌密度明显高于效果图。没有为贴图减少真实牌数。
- 复用现有狐狸、卡背及轨道；狐狸姿态、卡背月相位置和光迹形状与效果图不完全相同。
- 洗牌使用真实两组卡牌分开、交错和收拢，静态取样中的牌面角度与生成图不同。
- 牌桌与金箔是独立素材，纹理、雾光及部分边缘装饰不同；实际辅助文字与按钮为可操作控件，可读性和密度也有差异。

上述差异已列给用户作最终视觉验收。没有已知阻断使用的本轮问题；用户尚未对最终实页作视觉确认。

## 验证边界

本机 Chrome 独立无头浏览器，移动尺寸使用触摸模拟与 CDP 手势；不是 iOS / Android 微信真机。登录、配置、保存接口在测试会话中模拟，页面、DOM、图片、动画和事件处理为真实实现。没有调用真实解读模型、验证真实保存数据库、微信登录或手机软键盘及安全区。长问题检查两行展示及返回编辑保留全文；不能据此宣称覆盖所有中文字形或所有手机字体回退效果。
