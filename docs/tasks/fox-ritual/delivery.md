# 洗牌与抽牌主题实施结果

日期：2026-09-11。依据用户选定第三种“狐狸相伴”与配套洗牌图，并在用户明确要求执行后实施。代码仍在当前工作区，未提交、推送或部署。

## 改动

- 两阶段共用局部标题、问题摘要、狐狸、字体和固定操作区；加入独立牌桌、烫金纹理和 Tabler 图标。
- 洗牌保留 idle / shuffling / ready，1600 ms 时长、跳过、重复洗牌、减少动态效果；换为两组牌分开、交错、收拢动画。洗好后仍需点击开始抽牌。
- 抽牌保留完整 78 张、预选、单指拨牌、向外拖出、双指缩放和平移、撤回及键盘操作。调整牌弧几何、卡背和布局；修复几何变更后的展开起点，以及 Chrome 触摸目标偏移导致的邻牌误选。
- 默认揭牌 CardBack 外观保持原实现，阶段外观显式传入；舞台和拖动浮层使用相同卡背。
- 保留名称、路由、离开回首页、牌阵规则、随机逻辑、抽齐进入揭牌、首次揭牌保存；未改接口、登录、数据库或其他页面主题。

主要文件：`app/reading/page.tsx`、`reading-flow.module.css`；`components/drawing/RitualScene*`、`CardDeck*`、`CardBack.tsx`、`CompactCardBack.tsx`、`FanDeck*`、`fan-geometry.ts`、`ManualDrawTable*`；`public/brand/ritual-theme/`；相关测试和字体子集脚本。

工作区在开始时已有大量修改/删除。本轮相关基线记录在 `baseline.patch`，没有清理或回滚原有改动。后续暂存必须按本轮 hunks 分组，不得直接提交整个工作区；基线补丁和中间失败截图仅为调查证据，不应混入产品代码提交。

测试过程中出现的失败没有通过放宽断言解决：新增卡背测试与触摸回归测试均先失败后修复；初始几轮浏览器截图暴露的问题逐项修复。全量并发运行有一次未改动收藏页用例 5000 ms 超时，独立运行 4 项通过；降低 worker 数后全套通过，没有修改超时或删除断言。26 项跳过沿用现有测试配置，不算通过。

五组手势用例包含 360 × 800 单张、390 × 844 三张、430 × 932 十张、390 × 659 短屏和 1440 × 1000 桌面。覆盖真实触点命中、拨牌、75%—200% 缩放、双指平移、短拖取消、达到距离后释放抽取、撤回归还原牌、抽齐自动进入揭牌、返回调整不立即跳回、首次揭牌只保存一次。单/三/十张不是与六视口的全组合穷举。

视觉详情与剩余差异见 [design-qa.md](design-qa.md)。素材来源、许可证和字体重建方法见 `public/brand/ritual-theme/README.md`。

## 交付边界

真实 Chrome 页面使用隔离模拟账号/配置/保存，未验证真实模型、数据库写入、微信登录、微信真机软键盘和安全区；未向真实账号写入测试记录。现有揭牌由组件测试与完整浏览器流程检查，其他页面未做全面截图回归。

最终视觉仍需用户验收。实际牌弧因保留 78 张比效果图更密，卡背、狐狸和光迹复用现有素材，不声称像素级复刻。验收后的建议提交顺序为：素材与阶段卡背；共享场景与洗牌；抽牌布局和手势修复。对应回归测试随改动提交；重叠文件按 hunk 整理或合并，避免制造无法独立工作的提交。
