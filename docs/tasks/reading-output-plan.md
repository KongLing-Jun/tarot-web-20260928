# 解读输出与微信阅读体验优化

日期：2026-09-10。依据：本任务中用户确认的执行计划。

## 已确定的产品行为

- 基于当前 web-view，覆盖手动占卜、聊天、追问和历史兼容；每日一牌与独立小程序迁移不扩展。
- 输出顺序为「核心解读 → 可采取的行动 → 各牌说明」，界面使用自然标题；正文咨询式表达，建议对应具体分析。
- 逐牌专业解析与模型思考分别默认折叠，流式更新保持用户选择，展开不发起请求。
- 信息不足先有限回应，再邀请补充一个关键背景；不编造事实或断言他人心理。
- 保留 Markdown、SSE、数据库结构和抽牌/重试规则；兼容旧结构和自由文本。
- 当前追问携带此前完成的同次占卜历史，去除思考；重生成不读取未来轮次。
- 用户上滑或展开详情暂停跟随，回到最新或发送问题恢复。

## 实施与验收

按测试、解析展示、提示词、上下文、手机联动、完整回归顺序实施；任务状态见 reading-output-todo.md。
