## 当前触发与保存规则

首页在登录就绪、成功读取引导状态且入口可见后自动启动：新老账号只要没有当前版本的确认记录，都展示一次。完成、跳过、Escape 或点击遮罩退出会保存；切到后台、离开页面、卸载或入口失效属于中断，不保存，下次进入首页仍可自动展示。一次挂载期间不反复自动启动。首页手动入口和「我的」重看入口始终可用。

迁移 `020_product_tours.sql` 在 `tarot_users` 上添加 `product_tour_version integer NOT NULL DEFAULT 0` 与 `product_tour_status text`，不新建表。`0/null` 表示尚未确认；正版本必须对应 `completed/skipped`。仅保存最近确认版本，不保留历次引导历史。同版本只能从跳过升级为完成，旧客户端不能覆盖较新版本。注册时间不参与判断，不回填“已看过”。

`GET/PUT /api/product-tour` 从会话确定账号，公开资料接口保持原状。引导开始前捕获专用账号摘要，保存时核对，防止换账号后的延迟结果串写。读取失败视为未知，不自动弹出；手动查看仍可用，无法保存时提示下次可能重现。结果写入不被普通卸载清理取消，但网络失败仍可能导致下次展示。并发页面在任一页面保存前可能同时展示，不保证跨页面全局仅展示一次。

微信账号跨设备保持状态。网页游客状态跟随游客账号，清除游客凭证后创建的新账号会重新展示；不自动合并游客与微信账号。五步文案、暖黑配色和按钮居中保持不变。

本次已在同一会话完成 Latest + Pro 初审及用户表方案复核。采纳两字段、版本优先、原子条件更新、成对 CHECK、账号绑定、区分主动退出与中断、迁移限时和隔离数据库测试；按用户选择不使用独立历史表。此前主动触发方案属于下文的历史基线。

自动验证：85 项前端/API/相关页面测试、7 项真实 PostgreSQL 隔离 schema 测试。包含旧/新用户默认值、重复迁移保留状态、同名约束不串表、非法状态拒绝、未来版本防回退、并发完成/跳过、重新登录持久化、资料更新不覆盖状态和账号隔离。开发库迁移与浏览器验收结果见根目录 `design-qa.md`。

## Pro 审阅

实现前在 Codex 内部浏览器显式选中「最新 / Latest」，确认 Pro 能力，发送不含源码和个人数据的方案摘要，并等待完整答复。

审阅会话：https://chatgpt.com/c/6ab4eb46-67b0-83e8-b9e2-1bad98ef247e

采纳：五步、主动触发、无欢迎弹窗、无本地持久化；精确锁定依赖；仅在开启后动态加载；一次性消费 replay 参数并保留其余查询和 hash；防止重复启动与异步回调在卸载后恢复；背景隔离、焦点约束及恢复；隐藏/缺失目标时退出；不向 Driver.js 插入用户或 AI 文本；移动端实测定位。

结合仓库作出的选择：项目为 App Router，但 replay 只在首页组件挂载后的浏览器 effect 中读取 URL，因此无需 useSearchParams 或额外 Suspense。现有导航只有一套 DOM，仍显式选取可见锚点。现有入场动画会改变锚点位置，因此等待有限入场动画完成，不等待无限环境动画。

Pro 要求真机验证作为上线门槛。本次交付是本地交互预览，已完成浏览器验证；微信 iOS/Android 真机、VoiceOver/TalkBack 和系统大字体尚未验证，不将模拟浏览器结果作为上线验收。

## 实现边界

- 首页控制器负责动态加载、加载锁、请求代次、页面隐藏/卸载清理。
- 独立运行模块使用五个静态步骤，处理缺失目标、焦点、背景 aria-hidden/inert、尺寸变化刷新。兼容不支持 inert 的宿主时，仍以指针限制和键盘/焦点捕获约束交互。
- 小横屏下先把主入口滚动到可视区上方，给提示内容留出空间；不缩小字号或按钮来挤压内容。
- CSS 只覆盖本引导的 popoverClass；无原生导航栏或微信胶囊覆盖能力。
- 库的动画与平滑滚动关闭；退出不计作业务完成，不记录用户行为。

## 柔和版迭代 · 2026-09-24

用户认可文案，但认为提示卡过于方正、硬朗。本轮仅修改 ProductTour 的局部样式与 stageRadius：22px 卡片圆角、低对比边框、暖黑雾面、暖米金标题、香槟色胶囊按钮、留白替代分隔线，高亮圆角为 8px。保持五步文案和原有功能。

在同一 Pro 会话显式选择 Latest 并确认 Pro，等待完整审阅后实施。采纳其小范围样式调整、维持字号、44px 点击区、实测颜色对比度与四种尺寸全部步骤的建议。短横屏复查发现外伸箭头导致容器内部横向滚动，因此在该布局隐藏装饰箭头；高亮与空间关联保留，其他尺寸仍有箭头。

验证：ProductTour 7 项现有测试通过，品牌检查、定向 ESLint、Prettier 与 diff 检查通过；四种尺寸的全部五步无目标重叠、按钮裁切或视口溢出，返回/完成/退出/焦点恢复正常。详细视觉比较与横屏修正见根目录 design-qa.md 最新条目。本轮不新增依赖或测试、不重复生产构建；微信真机、大字体及读屏仍是发布前待验项目。
