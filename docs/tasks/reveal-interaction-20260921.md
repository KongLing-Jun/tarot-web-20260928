# 揭牌与解读牌面交互调整

## 当前行为

- 揭牌阶段单击当前待揭牌即可翻开，移除先选中再点击的中间状态。保留按牌位顺序揭牌、重复点击保护、全揭菜单与用户主动开始解读。
