## 应先修什么

本轮暴露了一个设计前提问题：**分别评分不等于错误必须互斥。** 一条建议可能既改变目标，又编造前提，还不可执行。不能为了让三维看起来独立，预设其他两维一定满分。

下一版先做以下修订，再决定新的校准调用预算：

1. 明确每维可观察问题。目标只检查动作是否服务当前目标及拒绝目标；执行检查动作、控制权和已知限制；事实检查陈述/预设是否有来源。允许有独立证据的多维扣分，禁止凭整体印象连带扣分。
2. 重写夹带额外预设的对照；目标与约束有交叉时，明确允许的联合标签或在调用前冻结合理分值范围，而非事后按输出迁就标签。004、005、006、007、009、010 是优先复核条目。
3. 把严重错误校准从“唯一引文白名单”改为“必需命中错误 + 允许的同一错误出现位置”。仍禁止把执行错误当作事实编造，并继续检查合理回答误报。原文引用只能证明引用存在，理由是否正确仍要复核。
4. 增加新场景检验修订后的规则，覆盖必要澄清、合理暂缓、1 分条件含混，以及做法嵌入完整解读正文的情况。本批已用于诊断，应标为开发校准材料，不能再冒充独立验证集。
5. 裁判门槛达标后，再冻结单个生成变量及新预算。建议以 P0 为基线，只改行动指导中“已知约束 → 可控动作 → 待确认依赖”的表达要求；保持模型、思考档位、牌面、输出协议和题目不变。此候选尚未实现或调用，也未证明有效。
