# 用户意图识别交付记录

日期：2026-09-23。代码与本地模拟验证完成，真实数据库迁移及模型启用尚未执行。

## 交付范围

- 新增 `/api/intent`：模型提取任务、用户事实、目标、约束与缺失信息，代码验证结构和原文引用，保存按用户隔离的不可变快照。
- 接入手动场景占卜、普通提问、Agent 和追问。澄清阶段不抽牌；失败保留输入；修改、取消和重试旧追问使进行中的识别失效。
- 后续追问恢复初始问题及澄清消息，按稳定消息 ID 合并；不同时间相同表态仍保留。自动选阵、补牌决策与解读读取完整意图材料。
- 纠正、解释已有牌和有原牌的情绪支持复用原牌。换题建立新问题；重试、重新解读和重新抽牌保留对应意图关联。
- 系统规则与用户自由文本分离；服务端再次核对用户、问题、场景和记录绑定。旧记录和无引用请求仍兼容。
- 配置增加可选 `INTENT_RECOGNITION_ENABLED`，默认关闭，启用说明见 [USER-INTENT.md](../../docs/USER-INTENT.md)。架构文档已同步。
