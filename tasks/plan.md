## 实现决策

### 素材与样式

1. 复用现有 `miying-fox.webp`，核对裁切、清晰度与确认稿比例；确有差异时再生成独立素材。桌布、月相桌面和边缘摆件生成无文字、无卡牌、无狐狸的背景素材。装饰不得包含按钮、进度或问题。
2. 卡背先比较 `public/brand/spread-theme/card-back.webp` 与确认稿；复用文件本身，不修改原素材。通过现有组件的可选阶段外观参数传递，默认视觉不变。参数只负责素材展示，不引入新的业务状态。
3. 背景与狐狸独立布局，牌桌按容器适配，卡牌保持固定纵横比。页高增长时不拉长狐狸或卡背，不将手势舞台压扁以迁就插画。
4. 颜色、字体、间距与动效先复用现有 token；需要的主题参数集中在阶段 CSS 作用域，避免影响全局按钮、标题、揭牌页和其他页面。
5. 检查既有字体子集是否覆盖本阶段所有文案、动态牌阵/阵位名称；问题是用户输入，保留可靠中文回退。不得把标题、问题和按钮烘焙进图片。
6. 复用现有可用图标；项目无合适图标时选择最小可用的授权图标资源，仅引入所需图标。图标不能代替按钮的可访问名称。

### 布局与状态

| 阶段 | 舞台 | 主要操作 | 次要操作 |
| --- | --- | --- | --- |
| 洗牌前 | 整齐叠牌 | 开始洗牌 | 修改问题、修改牌阵 |
| 洗牌中 | 两组交错牌包，短暂金色光迹 | 洗牌中…，禁用 | 跳过洗牌动画；编辑保留当前行为 |
| 洗好后 | 牌堆收拢、光迹消退 | 开始抽牌 | 再洗一次、修改问题、修改牌阵 |
| 抽牌未预选 | 完整牌弧与真实进度 | 抽取这张，禁用 | 前后选牌、编辑、重洗；按实际已抽数量决定撤回可用性 |
| 抽牌已预选 | 当前牌轻抬、边缘明确高亮 | 抽取这张 | 保留拖出确认和其他现有操作 |
| 抽取后 | 原位置留空、进度更新 | 按最新状态显示 | 撤回恢复原位置和身份 |
| 抽齐后 | 沿用自动进入揭牌 | 揭牌页既有操作 | 未揭牌时返回调整；满额返回抽牌有“返回揭牌” |

- 顶部共用位置与风格，复用有限的阶段展示结构；仅在出现明确重复时抽取小组件，不建立新主题引擎。
- 上方问题与狐狸、中央牌桌、下方辅助操作和底部主要操作保持层级；长问题沿用现有摘要语义，换行安全，全文仍可通过既有修改问题入口查看，不新增弹窗。
- 正常手机尺寸显示完整默认牌弧与主要操作。320 px 宽或短屏优先缩小装饰、调整辅助操作换行，必要时页面纵向滚动；不能以截断牌弧或缩小触控目标强行塞进首屏。
- 底部动作区处理安全区和实际高度，页面预留对应空间。避免固定区遮挡牌堆、辅助操作或最后一行内容。
- 桌面保持内容宽度上限与清晰牌堆，不将手机画面横向拉满，也不新增侧栏业务。
- 确认稿中的牌桌透视和牌面大小是视觉目标；当前 FAN 的几何与命中坐标应保持一致，不给手势父容器叠加未经验证的透视。先用背景、卡背与舞台尺寸接近目标，仍有显著差异则记录对照后再决定是否调整几何。
- 图中的三个进度装饰若保留，必须随真实牌阵数量生成，不能对单张或十张牌阵固定显示三点；文字进度是权威信息。

### 动效与数据边界

- 保留当前 1600 ms 展示时长与 round 校验；换用分牌、交错、收拢的 CSS transform / opacity 动效。光迹独立且不接收点击，不让 78 张牌各自持续发光动画。
- ready 是现有状态，不由 animationend 再发明一套状态机；旧轮次、卸载或跳过后不得延迟回调覆盖新状态。
- 开始抽牌复用 FanDeck 的展开动画，保持顶部和背景稳定；不新增计时等待，不在展开时再次洗牌或改变索引。
- reduced-motion 下静态完成展示，所有按钮与状态仍可操作。
- 拖出浮层与舞台牌面使用同一阶段卡背；图片装饰 pointer-events:none，真实按钮保留焦点、键盘和 aria 状态。
